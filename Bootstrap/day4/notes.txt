        2) modal

            - We have another component modal similar to Alert Component.

            - Difference between alerts and modals are the alerts are embedded on the webpage (i.e. part of page ) modals are pop-up with content in the background.

            - modal can pop-up with content in the background.

            - modal is a dialog that we can control dynamically.

            - Bootstrap provides some classes for desiging the modals. 
                Classes

                .modal 
                .modal-dialog
                .modal-content
                .modal-header
                .modal-body
                .modal-footer
                .modal-dialog-centered
                .modal-dialog-scrollable
                .modal-fullscreen
                .fade ---> used for animation. (at various places)

                - to design modal we use above classes.

                - inside the modal we have to create dialog. and inside the dialog there will be modal content. and modal content have three section modal-footer ---> modal-body  --->  modal-footer.

                - to control the dialog how it will keep that will be possible by using the other classes like .modal-dialog-centered ---> .modal-dialog-scrollable ----> .modal-fullscreen

                - In HTML we learn element called <dialog>. here dialog is not display automatically. it is an hidden state. to show it we use open attribute there. open attribute we have add manually there and same mechanism learn as follow as example.

                - In a page there can be several models one for login, one for register , one for product details etc. then every modal needs an id for (unique id).

                - we create the modal but we cannot seen on the webpage. because modal are the dialog and and dialogs are usually hidden.

                - Now we need to open this modal when user click on button.

                - to handle such scenario modal have some attributes. 

                - If we have to dismiss any component we have attribute like data-bs-dismiss. data-bs-dismiss attribute is used to close component on click.

                Attributes : 

                    data-bs-dismiss  : used to close component on click.
                    data-bs-target : it referes to the ID of element
                    data-bs-toggle : It refers to click event for element.
                    You have to define component to function on click.

                Syntax : 

                    <button data-bs-toggle="modal" data-bs-target="#login"></button>

        3) Offcanvas : 

            - In latest version very recently introduce new one like Alerts and modal like Offcanvas.

            - Offcanvas is Recently Added Component In Bootstrap.

            - Offcanvas is similar to modal but provides a dialog that can span in any orientation.

            - Offcanvas is good for Desingings nav-bars.

            Classes : 

                .Offcanvas
                .Offcanvas-start
                .Offcanvas-end
                .Offcanvas-top
                .Offcanvas-bottom
                .Offcanvas-header
                .Offcanvas-body
                .Offcanvas-footer

            Attributes : 

                tab-index = "-1"  ---> by default it is not active ( dialog are by default are inactive but offcanvas are by default active so to change their state we have to use tab-index = -1 to change it state active to inactive). 

                data-bs-dismiss
                data-bs-target
                data-bs-toggle
            
            - There are three type of alerts in bootstrap Alerts, Modals, Offcanvas.

            - Offcanvas is mostly used to design toolbar, navbar etc.

        4) Carousel :

            - It is Important Bootstap Component used in many of the website to show case hero-section of website.

            - It is used to design sliding and fading content in page.

            - It can be controlled manually or with auto timing.

            Basic Carousel Classes : 

                - This are three important classes.

                .carousel 
                .carousel-inner
                .carousel-item 

                - Make sure that one carousel-item is should be "active". not all carousel-item should not be "active".

                    <div class="carousel-item active"></div>

                - Carousel will not have any default animation, to start animation you have to define the attribute "data-bs-ride=carousel"

                - Carousel will not have a smooth animation, to define animation you have to apply the classes "slide" or "carousel-fade".

                - these are the basic carousel. in many website these types of carousel are used which will be (slide or fade) scroll. 

                - But some of the website carousel are like to visit previous carousel-item and visit next carousel-item. that means carousels needs next button and previous button 

                - Basic Carousel Example : 

                     <!-- Basic Carousel -->
                    <div class="carousel carousel-fade" data-bs-ride="carousel" id="banners">
                        <div class="carousel-inner">
                            <div class="carousel-item active">
                                <img src="./images/slide1.png" alt="slide1" height="200" class="w-100 d-block">
                            </div>
                            <div class="carousel-item">
                                <img src="./images/slide2.png" alt="slide2" height="200" class="w-100 d-block">
                            </div>
                            <div class="carousel-item">
                                <img src="./images/slide3.png" alt="slide3" height="200" class="w-100 d-block">
                            </div>
                        </div>
                    </div>

                - Carousel Controls :

                    - it is not mandetory but if required then you can use it for control the carousel(like previous or next).

                    - Carousel Provide following classes to control carousel.

                        .carousel-control-previous 
                        .carousel-control-next
                        .carousel-control-prev-icon
                        .carousel-control-next-icon
                    
                    - The above carousel control require some attributes as follow :

                        data-bs-slide = "prev"
                        data-bs-slide = "next"
                        data-bs-target = "#carousel_id"
                        data-bs-theme ="dark"

                    - If the contols are darker we can appply 
                        data-bs-theme = "dark"

                    - There no controls to the carousel control button right now so we have to use following attributes in that button

                    data-bs-slide = "prev/next"
                    data-bs-target = "banners(carousel id)"

                    - Classes

                        .carousel-indicators

                        data-bs-slide-to = "0\indexNumber" [ indexNumber stars from 0 to n-1]
