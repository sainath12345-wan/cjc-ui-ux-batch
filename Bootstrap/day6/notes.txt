                <!-- 
                
                &laquo;   for  << 
                &raquo;   for  >>
                -->
                <h2>Pagination</h2>
                <ul class="pagination">
                    <li class="page-item"><a class="page-link"> &laquo;</a></li>

                    <li class="page-item disabled"><a class="page-link">4</a></li>

7) Bread Crumb

    - It is important/popular  component in web designing. but you rquire good knowledge (complete) of css also.

    -You are doing some shopping in the they some steps.
        step1 : select a product
        step2 : add to cart.
        step3 : select the payment 
        step4 : enter you details.
        step5 : checkout.

    - You know some websites show status like banking or etc .
        s1,s2,s3, currenlty you are in which step , how many steps are there such know as bread crumb.

    Classes : 

        .breadcrumb
        .breadcrumb-item
        .active

    - actually showing the bread crumb you will learn in css selectors. how to design bread crumb like this by your own seperator. 

    - Example By using Bootstrap.
