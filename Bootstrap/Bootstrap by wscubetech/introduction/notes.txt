    *) Bootstrap Breakpoints : 

        - bootstrap divides in 6 screens as follow as.

          xxl --- >= 1400px (min-width) ---> (Big TV, Big Computer , Large Devices)
           xl --- >= 1200px (min-width) ---> ()
           lg --- >= 992px (min-width)
           md --- >= 768px (min-width)
           sm --- >= 576px (min-width)
           xs --- <= 576px (max-width)

           xxl , xl , lg ---> laptop , computer , large screen devices.

           md, sm ---> tabs , medium screen devices

           xs ---> small screen devices (mobile).

    *) Bootstrap Containers : 

        Website have two parts one is full width area (100%) and another one is middle area.

        To make such parts on website by using bootstrap container classes. following are the classes are used to achieve above functionality.

            .container-fluid
            .container
            .container-xxl
            .container-xl
            .container-lg
            .container-md
            .container-sm
            .container-xs

            - but we use mostly following two classes.

            .container-fluid :  it gives alwasy 100% width.

            .cotainer : it is used for container inside the container-fluids. (middle part)

            - If you want to situation like that if screen size have greater than 1400 then width takes 1200px rather than 1320px. it achive by applying own custom style.

                syntax of bootstrap : 
                @media (min-width: 1400px) {
                    .container-xxl, .container-xl, .container-lg, .container-md, .container-sm, .container {
                        max-width: 1320px;
                    }
                }
                
                
                syntax of custom css : 
                @media (min-width: 1400px) {
                    .container-xxl, .container-xl, .container-lg, .container-md, .container-sm, .container {
                        max-width: 1200PX;
                    }
                }

    - Gutter Classes  : 

        - By using gutter classes we can adjust gap in between columns.

        - Gutter class is a row class.

        - gx --> it works on x-axis  (left and right) (manage padding between columns)   
        - gy --> it works on y-axis  (top and bottom) (manage margin between columns)

        - .gx-0 -- x axis gap is zero beteen column. (remove all padding.)
          .gx-1 --  ( it adds 2px padding)
          .gx-2 --  ( it adds 4px padding)
          .gx-3--  ( it adds 8px padding)
          .gx-4 --  ( it adds 12px padding)
          .gx-5 --  ( it adds 24px padding)

    - Typography Classes :

        Margin Classes : 

            .m{0|1|2|3|4|5} -- all directions
            .my{0|1|2|3|4|5} -- top/bottom direction (y-axis)
            .mx{0|1|2|3|4|5} -- left/right direction (x-axis)
            .mt{0|1|2|3|4|5} -- top
            .mb{0|1|2|3|4|5} -- bottom
            .ms{0|1|2|3|4|5} -- left
            .me{0|1|2|3|4|5} -- right.

            - bootstrap works on "rem" unit  (1rem = 16px)

            m-0 -- 0rem -- 0px 
            m-1 -- 0.25rem -- 4px
            m-2 -- 0.5rem -- 8px
            m-3 -- 1rem -- 16px 
            m-4 -- 1.5rem -- 24px 
            m-5 -- 3rem -- 48px

            similar for all .m, .mx , .my, .mt, .mb, .ms, .me etc.
