6) Accordion

    - It uses a mutex mechanism to show or hide content.
    - Mutex is "Mutual Exclusion".
    - It hides all other contents in a category when any one is selected.

    - There are Accordion classes to build it.

    Classes : 

        .accordion
        .accordion-item
        .accordion-content
        .accordion-header 
        .accordion-body
        .accordion-collapse
        .accordion-button
    
    - It have some attributes for more functionality : 

    Attributes : 
        
        data-bs-target
        data-bs-toggle
        data-bs-parent
    
    - Collapse and Accordion are different.

    - Inside every accordion item have accordion-header and accordion-body.

    - if we use class as .show in accordion-collapse it will display to its body.

    - How to achieve the property which when click one item then other hides its body and body of clickable item only shown.

        - 1 . give accordian to id like "faq"
        - 2. each accordion-collapse uses attribute like data-bs-parent with its value is "accordion-id(faq)".

7) Dropdown :

    - This is next compoent which is most important to build website many time it will used that is dropdown.

    - HTML drop down are designed by using selects.

    - Drowback of HTML Drop downs according to design wise they do not allow icons, image, symbols or any thing inside them.

    - Example : Netflix language drop down menu.

    - HTML dropdown will not allow symbos, icons or images as it it  "RC datat type".
      [Rich Content Data Element]

    - Bootstrap dropdown allows complex content. [symbols, icons, links, formats...]

    - Classes : 

        .dropdown
        .dropup
        .dropend
        .dropstart
        .dropdown-menu
        .dropdown-item
        .dropdown-toggler
        .dropdown-divider
        .dropdown-item-text

    - Attributes : 

        data-bs-toggle="dropdown"

        this only one attribute is used in this.

    - difference between html dropdown and bootstrap dropdown

    In htm dropdown we can show complex content but by using bootstrap dropdown we can achive it.

    Example : 

        <!DOCTYPE html>
        <html lang="en">
            <head>
                <meta charset="UTF-8">
                <meta name="viewport" content="width=device-width, initial-scale=1.0">
                <title>Bootstrap workshop : session 5 (Drop Down Menu) </title>

                <!-- Bootstrap CDN Links -->
                <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">
                <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" crossorigin="anonymous"></script>
                <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.13.1/font/bootstrap-icons.min.css">

            </head>
            <body class="container-fluid">

                <!-- outside the select drop menu icon is working propertly-->
                <span class="bi bi-globe"></span>
                <select>
                    <!-- Inside the select inside the option icon is not working properly. -->
                    <option> <span class="bi bi-globe"></span> Language</option>
                    <option>English</option>  
                    <!-- check box is also not use directly inside the drop down if we want to use then we have use bootstrap drop down -->
                    <option><input type="checkbox">Hindi</option>
                </select>



                <!-- dropdown inside dropdown achieve by using javascript -->
                <!-- Create a Dropdown menu using bootstrap -->
                <div class="dropdown">
                    <button data-bs-toggle="dropdown" class="btn btn-dark dropdown-toggle" ><span class="bi bi-translate"></span>Flipkart</button>

                    <!-- to item we create ul -->
                    <ul class="dropdown-menu" data-bs-theme="dark">
                        <li class="dropdown-item"><span class="dropdown-item-text"><span class="bi bi-person-circle"></span>Profile</span></li>
                        <li class="dropdown-item"><span class="dropdown-item-text"><span class="bi bi-heart"></span>Wishlist</span></li>
                        <!-- .dropdown-divider used to divide dropdown -->
                        <li class="dropdown-divider"></li>
                        <li class="dropdown-item"><span class="dropdown-item-text"><span>Help</span></span></li>
                    </ul>
                </div>
            </body>
        </html>




8) Nav & Tabs : 

    - Nav and Tabs are very popular in website designing.

    - They can create tab based navigation.
    - You can display multiple categories of content in the one page.
    - User can Switch between categories dynamically.
    
    - Classes : 

        .nav
        .nav-tabs
        .nav-pills
        .nav-item
        .nav-link
        .tab-content
        .tab-pane
        .active

    - Tab-based navigation : user can switch and select from one. instead of desiging several pages you design single page with mutiple content that will done by using the Tab-based navigations / nav with tabs. 

    - tab have different style also like tab-pills.

    Note : If you are using <a> element then you can define "href" as "data-bs-target".

    Syntax : 

        <button data-bs-target="#login" data-bs-toggle="tab">
        <a href="#login" data-bs-toggle="tab">

    Example : 

        <!DOCTYPE html>
        <html lang="en">
            <head>
                <meta charset="UTF-8">
                <meta name="viewport" content="width=device-width, initial-scale=1.0">
                <title>Bootstrap workshop : session - 5 (Nav and Tabs)</title>
                <!-- Bootstrap CDN Links -->
                <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">
                <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" crossorigin="anonymous"></script>
                <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.13.1/font/bootstrap-icons.min.css">

            </head>
            <body>
                
                <!-- navbar -->

                <h1>Shopper</h1>
                <ul class="nav nav-tabs "> <!-- nav-pills for different sturcture of nav-tabs.-->
                    <!-- data-bs-target is only required for button not for links. same data-bs-target working do in achor tag by help of href attribute -->
                    <li class="nav-item "><a class="nav-link active" href="#login" data-bs-toggle="tab" >Login</a></li>
                    <li class="nav-item"><a class="nav-link" href="#register" data-bs-toggle="tab">Register</a></li>
                    <li class="nav-item"><a class="nav-link" href="#recover" data-bs-toggle="tab">Recover Account</a></li>
                </ul>

                <div class="tab-content">
                    <!-- tab-pane -->
                    <div class="tab-pane active" id="login">
                        <dl>
                            <dt>User Name</dt>
                            <dd><input type="text"></dd>
                            <dt>Password</dt>
                            <dd><input type="password"></dd>
                        </dl>
                        <button class="btn btn-primary">Login</button>
                    </div>

                    <div class="tab-pane" id="register">
                        <dl>
                            <dt>User Name</dt>
                            <dd><input type="text"></dd>
                            <dt>Password</dt>
                            <dd><input type="password"></dd>
                            <dt>Mobile</dt>
                            <dd><input type="text"></dd>
                            <dt>Age</dt>
                            <dd><input type="number"></dd>

                        <button class="btn btn-primary">Register</button>
                    </div>

                    <div class="tab-pane" id="recover">
                        <input type="email" name="" id="" placeholder="Your email">
                        <button class="btn btn-primary">Recover</button>
                    </div>
                </div>
