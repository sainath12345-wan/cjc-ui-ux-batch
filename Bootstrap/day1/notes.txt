1. What is Bootstrap ? 

    - It is a Component library used to build interactive UI faster.

    Component Library : it is nothingbut already some templates are designed and given to you and you have just implement them and customize according requirement.

    It is an open source and cross platfrom library for building UI.

    Open Source : it means customize according to our requirement.

    Free : licence freely (we can use without purchasing that).

    cross-platfrom : it can run on every browser.

2. Component library ? 

    A Component comprises of 
        a) Markup         ----> (HTML)
        b) Styles         ----> (CSS)
        c) Functionality  ----> (JAVASCRIPT)

    // boostrap style file link in head section.
    // css files order is not matter.
    <head>
        <link rel="stylesheet" href ="../node_modules/bootstrap-icons/font/bootstrap-icons.css">
        <link rel="stylesheet" href ="../node_modules/bootstrap-icons/dist/css/bootstrap.css">
    </head>

    // boostrap script file link in body section.(we can add script inside the head section also but recommended way to add script in body section is good)

    // js files order is matter.

    <body>
        <script src="../node_modules/jquery/dist/jquery.js"></script>
        <script src="../node_modules/bootstrap/dist/js/bootstrap.bundle.js"></script>
    <body>

Bootstrap Icons : 

- bootstrap provides lots of icons.

- Every icon is defined using class name.

    bi bi-Twitter
    bi bi-facebook
    bi bi-house
    bi bi-person-fill

- Classes are applied to any HTML element by using "class" attribute.

    https://icons.getbootstrap.com/ --> visit this website to get all classes required to the bootstrap icons.
    

To use bootstrap and icons in any page you can link CDN directly and implement. (without installing package manager.)

CDN : some files kept on the server and to access that files without downloading and installing we have to use then some links are created such links are called as CDN (content delivery links).


#) Steps to set up the CDN our project :

1) Visit the website "getbootstrap.com".
2) Click on "Download".
3) Go ot "CDN" category

4) Copy the links and paste in Head section of page.

     <!-- Bootstrap CDN Links -->

    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">

    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" crossorigin="anonymous"></script>
