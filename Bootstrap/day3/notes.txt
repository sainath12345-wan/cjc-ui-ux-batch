    4.) Form Classes : 

        - following classes are provides bootstrap to working with the forms.

            .form-label     - it is used for element like <label>
            .form-check-label - it is used for element like <label> for radio or checkbox.
            .form-control       - it is used for text, password, number, date, url, email, textarea etc..
            
            .form-select    - it is used for <select> element or creating dropdown menus

            .form-control-color     - it is used for <input type="color">

            .form-control-file      - it is used for <input type="file">

            .form-range         - it is used for <input type="range" >

            .form-check-input       - it used for radio or checkbox.

            .form-switch        - it is used for radio or checkbox container. (radio or checkbox container means in which container kept radio button or checkbox button for that container we have to use class called .switch)


            - Now We want to design a form traditionally  you learned in HTML how to create a professional form.
            Order for form designing like this.

                - In side form every category kept in seperate Div. category means username, password , address like are the different categories.

                - Inside Every category have its corresponding label and element.

                - these are rules for developing professional forms you have to Remember this rule at the developing the form.

            - This all are the classes which are reqired to develop professional forms. to design forms this classes are enough.

    5.) Bootstrap Components (very very important)   : Interactions

        - Till Now we work with bootstrap classes to design  but now we work with some functionalites also.

        - There are so many Bootstrap compoents we seen as follow as :

        1) Alerts 

            - main use case of Alert Component which is displays the message box and control it dynamically (open and close at dynamically).


            - it is an embedded message box displayed in page.
            - You can dynamically close the message box.

            Classes :
             
                - following are the classes required for Alerts compoents.

                .alert
                .alert-dismissable
                .alert-{contextual}
                .alert-title
                .alert-subtitle 
                .alert-link 

            - There classes are not enough so some of the attributes are also present as follow as :

            Attributes :  [ to control interactions ]
                
                - Attributes are used to control the interactions.

                data-bs-dismiss       - it is used to close any component pm click.

            Example :

                    <!DOCTYPE html>
                    <html lang="en">
                        <head>
                            <meta charset="UTF-8">
