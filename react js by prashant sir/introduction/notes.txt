#) What is React :

    - Javascript library to build Dynamic and interactive user interfaces.
    - Developed at Facebook in 2011.
    - Currently most widely used JS library for front-end development.
    - Used to create single page application (SPA).

#) Working Of DOM :

    - Browser takes HTML and create DOM.
    - JS helps use modify DOM based on user actions or events.
    - In big applications, Working with DOM becomes complicated.

#) Problems with Javascript : 

    1. React has a simpler mental model. (E.g. Inverter on/off)
    2. Js is cumbersome.
    3. JS is Error-prone.
    4. JS is Hard to maintain.  

#) Working of React : 

    1. No Need to worry about querying and updating DOM.
    2. React creates a web page with small and reusable componets. 
    3. React will take care of creating and updating DOM Element.
    4. It saves a lot of time, cheezein aasan hai, pehele se likhi hui hai.

#) JS VS React : 

    1. JS is imperative : You define steps to reach you desired state.

    2. React is Declarative : You define the target UI state and then react figures out how to react that state.

    To Visit React Components In Dev Tools : 

    Go to Dev Tools ---> select more tools (>>>) ---> select Components


#) Introduction to components 

    - Components help us write reusable, modular and better organized code.

    - React application is a tree of components with App component as the root bringing everything together.
